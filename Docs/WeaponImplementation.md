# 5종 무기 구현 및 검증

2026-10-23 기준. 목표 기획은 [WeaponDesign](WeaponDesign.md), 개편 전 코드의 수치는 [WeaponCatalog](WeaponCatalog.md)에 기록했다. 여기 적은 신규 수치는 **플레이 검증용 임시값**이며 확정 밸런스가 아니다.

## 1. 적용한 동작

| 유탄 발사기 | 유탄 충돌·시간 만료 지점에 약한 직접 피해와 화상 장판 생성. 스킬은 주변 화상 3중첩 즉시 부여. 필살기는 조준 지점 주변에 폭격과 무작위 지속 피해 | [GrenadeLauncher](../Assets/PlayerSystem/Weapons/GrenadeLauncher.prefab) |

신규 3종은 프로젝트에 포함된 무기 스프라이트와 총구·탄도·명중·화염 이펙트를 연결했다. 샷건 필살기의 떠다니는 무기도 본체 스프라이트를 사용한다. 에셋 대응은 아래 6절을 참조한다. 현재 `SamplePlayer`의 선택은 샷건이다.

## 2. 조작·설정

플레이용 [SamplePlayer](../Assets/PlayerSystem/SamplePlayer.prefab)의 `Player.weapon` 필드에 원하는 무기 프리팹을 지정한다. 씬에 플레이어 인스턴스가 있으면 그 인스턴스에서 덮어쓸 수 있다. 무기 프리팹을 플레이어와 별도로 씬에 놓는 방식이 아니라 `Player.Start()`가 생성·등록하는 기존 경로를 사용한다.

- 저격총: 마우스 왼쪽 버튼을 눌러 조준, 놓으면 일반 공격.
- 건/나이프: 클릭 즉시 발사. 차지·차지에 따른 퍼짐 감소와 시험용 추가 4발 제거. 기본 1발, 탄환 수 스탯에 따라 증가. 전체 퍼짐각 20도 고정.
- 돌격소총: 마우스 왼쪽 버튼 유지로 연사, R로 수동 재장전. 탄창이 비면 자동 재장전.
- 유탄 발사기·샷건: 마우스 왼쪽 버튼을 누를 때 일반 공격.
- 모든 무기: E 스킬, Q 필살기.
- 5종 모두 화면 하단 중앙에 스킬 충전·필살기 에너지와 무기별 상태를 표시한다. 설정·확장 구조·화면 예시는 [무기 HUD](WeaponHud.md)를 참조한다.

공통 입력·충전: [ChargedWeapon](../Assets/PlayerSystem/Weapons/ChargedWeapon.cs). 신규 투사체: [WeaponProjectile](../Assets/PlayerSystem/Weapons/WeaponProjectile.cs). 지속 피해는 [WeaponDamageOverTime](../Assets/PlayerSystem/Weapons/WeaponDamageOverTime.cs)으로 기존 `DamageOverTime`을 상속해 지속 피해 추가 발동 효과와 연결했다.

## 3. 임시 수치와 해석

신규 무기 3종의 필살기 비용은 60, 에너지 상한은 100이다. 스킬은 가득 찬 상태로 시작한다. 스킬 충전 시간은 아래 기본값에 `4/(쿨다운 감소 스탯+4)`를 곱한다. 기본 스탯은 1이므로 기본값의 80% 시간이 걸린다.

| 무기 | 임시 설정 |
|---|---|
| 돌격소총 | 탄창 30, 재장전 1.8초, 기본 사격 간격 0.12초, 1발 피해 계수 30%, 명중 에너지 1.5. 스킬 충전 기본 8초·최대 4회. 필살기 10초 동안 연사 배율 1→3배 |
| 유탄 발사기 | 발사 간격 0.8초, 직접 피해 계수 25%, 장판 반경 2·4초. 진입 즉시·0.5초마다 계수 4% 접촉 피해와 화상 갱신. 화상은 1초마다 8%, 갱신 지속 2초. 스킬 반경 6·3중첩·각 틱 25%·6초. 스킬 기본 충전 6초·최대 2회 |
| 유탄 폭격 | 8발, 0.25초 간격, 조준 지점 반경 5 안에 낙하, 폭발 반경 2·계수 60%. 마지막 1발은 중앙에 대형탄으로 낙하(피해 수치는 다른 폭탄과 동일). 폭탄마다 열·전기·물리 중 하나를 동일 확률로 선택해 틱 계수 20%·6초 지속 피해. 후보 배열은 Inspector에서 변경 가능 |
| 샷건 | 기본 8탄환, 퍼짐각 20도, 탄환당 계수 18%, 사격 간격 0.7초. 스킬 기본 충전 5초·최대 1회, 5초간 명중 탄환당 에너지 6. 평상시는 발사 전체의 에너지 합계가 0.5가 되도록 탄환 수로 나눔 |
| 샷건 필살기 | 탐색 반경 15, `5 + max(0, floor(bulletRate)-1)`정, 샷건당 계수 400%. 조작 잠금 → 0.85초 감속과 동시에 몸에서 사출 → 사출부터 총 1.65초 큰 곡선 비행 → 적과 2.6 거리에서 0.22초 조준 → 전 총 발사 연출 후 피해 처리 → 0.18초 여운·0.22초 시간 복귀. 모두 현실 시간 |
| 건/나이프 | 스킬 기본 충전 6초·최대 2회, 필살기 비용 60·상한 100. 조준 지점 반경 6 안의 기존 표식을 1회 명중 상태로 변경. 표식 폭발 600% 계수·스킬 피해 |
| 저격총 | 기존 프리팹의 스킬 최대 4회, 기본 쿨다운 5초, 필살기 비용 60·상한 100 유지. 필살기 이벤트 에너지도 실제 비용 60으로 일치 |

돌격소총은 공격 속도와 필살기 연사 배율을 곱해 사격 간격을 줄이며 최저 간격은 0.02초다. 스킬 즉시 재장전은 남은 재장전 시간을 취소하고 탄창을 채운다.

화상 3중첩은 독립된 지속 피해 인스턴스 3개다. 장판은 콜라이더가 닿은 대상에게 진입 즉시·0.5초마다 접촉 피해를 주고 자체 화상 1개를 갱신한다. 화상 틱 간격은 1초이며 갱신으로 틱 시계를 초기화하지 않는다. 범위 밖에서는 접촉 피해 없이 잔여 화상만 적용된다. 폭격은 지정한 도착 지점에서 폭발하며 중간 지형·콜라이더로 폭발 위치가 바뀌지 않는다.

샷건 스킬의 충전 여부와 탄환당 에너지 값은 **발사 시점**에 결정한다. 한 탄환은 최초 명중 대상에만 피해·에너지를 주고 소멸한다. 필살기는 발동 시 범위 내 살아 있는 적을 **현재 HP 내림차순**으로 정렬해 최대 5명을 선택한다. 동률은 인스턴스 ID로 순서를 고정한다. 배분은 1명 5 / 2명 3·2 / 3명 2·2·1 / 4명 2·1·1·1 / 5명 1·1·1·1·1이다. 발동 시 대상이 없으면 에너지를 소모하지 않으며, 연출 중 사라지거나 사망한 대상의 배정은 재분배하지 않는다.

건/나이프 필살기는 사용 순간의 구역만 검사하고, 표식이 없는 적에는 새 표식을 만들지 않는다. 표식 폭발에 필요한 명중은 해당 표식을 만든 플레이어의 일반 공격만 센다. 기본 공격은 표식 해제를 보조하고 칼 공격은 스킬 태그로 분리했다.

## 4. 함께 수정한 기존 문제

| 영역 | 수정 |
|---|---|
| 피해 태그 배열 | 태그 개수 대신 최대 태그 값+1로 크기 계산. 값 60인 화염구 태그의 배열 범위 오류 방지 |
| 이벤트·버프 | 리스너·버프 중복 등록 방지, 이벤트 처리 중 리스너 제거에 안전한 순회, 공격자 없는 사망 이벤트 처리 |
| 엔티티 수명 | 파괴 시 TimeManager와 체력바 정리, 체력바·인벤토리 참조가 없는 샘플의 일부 null 접근 방지 |
| 트리거 | ImpactFeedbackLoop의 피해·공격자 필터와 속도 연동, ChainLoadingProtocol의 쿨다운 검사. 모두 효과 실행 전에 쿨다운을 설정해 재진입 방지 |
| 저격총 | 스킬 피해 분류·실행 이벤트·필살기 이벤트 비용 수정. 스킬·필살기 직접 호출의 비용 검사, UI 0 나눗셈과 시간 배율 복원 보완. 스킬/필살기는 엔티티 단위로 중복 타격을 제한하고, 쿨다운 감소 스탯이 0 이하일 때의 즉시 충전 오류 수정 |
| 건/나이프 | 런타임 표식 관리자 생성·정리, 스킬 스택 소모·충전, 에너지 상한, 칼의 피해 태그·수명, 필살기 구현. 기존 무기 탄환도 부모 엔티티를 찾아 자식 콜라이더 명중 처리 |
| 공용 Projectile | 파워·피해 보너스·넉백·반동이 저장만 되고 실제 사용되지 않던 문제 수정 |
| 기존 효과 | Shock 수명 감소, UltimateCapacitor의 파워 하한·상한·종료 정리, 추가타 구체 개수 제한·중복 예약, AssaultStackBuffer 상한, RecoveryManager 에너지 소모·재충전 지연, RiskAnalyzer 이름·기본 지속시간, OverclockConverter HP 비용, AtkUpByPower 만료·개체 상태 수정 |
| 독립 스택 버프 | 첫 등록 시 실제 스택 생성 누락 수정 |
| 메모리 콜백 | 투사체 콜백이 다른 피스의 마지막 파워를 읽지 않도록 등록 시 파워 캡처 |
| 시간 정지 | 고정 물리 시간 간격이 0이 되지 않도록 보호. 샷건 연출은 현실 시간으로 진행하며 무기 비활성화 때도 정리·시간 복원 |

이 수정은 게임 전체의 모든 문제를 해결했다는 뜻은 아니다. 예를 들어 메모리 보드의 빈 이벤트 수신 경로, 일부 기존 효과의 정적 버프 공유, 보드 UI 활성 상태에 의존하는 효과 시간 처리는 장비 개편 때 추가 정리가 필요하다.

## 5. 검증

- 관련 런타임 C# 소스를 설치된 Unity 6000.3.24f1의 엔진 참조와 Roslyn으로 컴파일해 오류가 없는지 확인했다. 원본 프로젝트 버전은 변경하지 않았다.
- [WeaponRulesTests](../Assets/Tests/Editor/WeaponRulesTests.cs)의 9개 사례에서 샷건 배분 1~5명·초과·대상 없음과 공격 속도/필살기 연사 배율 규칙을 검증했다. Unity Test Runner의 EditMode에서도 실행할 수 있다.
- 격리된 임시 Unity 프로젝트의 Editor에서 실제 컴포넌트를 생성해 **14개 검사**를 통과했다. 탄창 소모→재장전, 즉시 재장전과 스킬 1회 소모, 최대 4회 재충전, 1회 명중 표식 폭발과 표식 제거, 샷건 대상 없음 시 에너지 보존을 확인했다. 기존 코드 회귀 검사로 희소 태그 피해 계산, 공격력 버프 적용·중복 방지·만료, 필살기 축적 상한·만료, 공격자 없는 사망 이벤트도 확인했다.

별도의 Unity URP 프로젝트에서 신규 3종의 프리팹을 불러와 본체 이미지·시각 에셋 참조와 좌우 조준 모습을 확인했다. 원본 Play 씬에서 다섯 무기를 직접 조작하는 전체 플레이 테스트는 아직 하지 않았다. 씬에서 추가로 확인할 항목은 다음과 같다.

1. 각 프리팹으로 E/Q 사용·사격·사망·무기 비활성화를 수행하고 오류·리스너 잔존·시간 배율을 확인한다.
2. 저격총 일반/스킬/필살기 피해 태그와 연계 트리거가 기대대로 반응하는지 확인한다.
3. 유탄 장판·3중첩 화상·폭격의 범위·중첩·만료·에너지 흐름을 확인한다.
4. 샷건 필살기를 적 1~5명과 체력 동률·연출 중 사망 상황에서 확인한다.
5. 과거 무시되던 Projectile 파워를 사용하는 기존 에셋의 피해량을 재조정한다.

원본 탄도 프리팹의 이동 스크립트·물리 컴포넌트와 기존 화염 프리팹의 피해 스크립트는 **새 시각 전용 프리팹에서 제외**했다. 피해·이동은 새 무기 코드가 담당해 중복 적용을 막는다. 원본 패키지 프리팹은 수정하지 않았다.

검증 이미지: [무기 본체와 좌우 조준](Previews/WeaponVisuals.png), [탄도·총구·명중·폭발·화염](Previews/WeaponEffects.png). 두 이미지는 연결된 프리팹과 기존 에셋을 Unity URP에서 직접 렌더링한 결과다. 3종 무기의 이미지·참조 검증과 5개 입자 이펙트의 생성·머티리얼·입자 표시 검증을 통과했다.

탄환은 총구에서 생성하며, 총구가 벽 너머로 나간 경우 플레이어와 총구 사이의 충돌 지점에서 생성해 벽을 뚫고 발사되는 것을 방지한다. 이미지를 연결하지 않은 코드 단독 시험 오브젝트에 한해서는 기존 선 표시를 대체 표현으로 사용한다.


## 7. 연출·HUD 재작업

[무기 연출 변경 내역](WeaponPresentation.md)에 샷건 단계별 타이밍, `alveria` 메테오 참고 경로, 유탄 낙하 판정·소형/대형탄 구성, 기본 에너지 하향과 건/나이프 발사 변경을 정리했다. HUD는 하단 중앙의 실루엣·스킬 분할 게이지·필살기 원형 게이지로 변경했다.

건/나이프의 최종 처형 기획은 플레이어가 표식 대상 위치로 이동해 내려찍는 공격이다. 아트 작업 전까지 보류했으며, 현 코드의 1회 명중 표식 상태를 만드는 필살기는 임시 동작으로 남긴다.
