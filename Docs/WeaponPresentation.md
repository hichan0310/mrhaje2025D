# 무기 연출·조작 재작업

2026-10-23. 현재 적용 코드·프리팹 기준이며 모든 시간·간격·에너지 수치는 Inspector에서 추가 조정 가능하다.

## 샷건

일반 공격의 평상시 에너지는 **탄환당 0.5 → 발사 전체 합계 0.5**로 낮췄다. 기본 8탄환을 모두 맞히면 기존 4에서 0.5가 된다. `normalVolleyEnergy / 발사 탄환 수`를 각 탄환에 배분하므로 추가 탄환으로 평상시 에너지가 급증하지 않는다. E 이후에는 기존대로 명중 탄환마다 6 에너지를 얻는다. 에너지 충전 스탯은 두 경우 모두 기존 규칙대로 곱한다.

필살기는 다음 순서로 재생한다. 시간은 `Time.unscaledDeltaTime` 기준이다.

| 단계 | 기본 시간 | 동작 |
|---|---|---|
| 입력 잠금 | 즉시 | 이동·점프·회피·공격·스킬 입력 차단. 무기 본체는 잠시 숨김 |
| 감속·사출 | 0.85초 | 세계 시간을 1→0으로 점진 감속하며 몸 위치에서 샷건들을 사출. 비행과 동시에 진행 |
| 큰 곡선 비행 | 사출부터 총 1.65초 | 위·아래로 크게 휘는 한 번의 곡선을 따라 이동. 나선 운동·제자리 공전은 사용하지 않음. 비행 중 한 바퀴 회전하고 도착 전 회전을 마친 뒤 적을 향해 정렬 |
| 조준 고정 | 0.22초 | 목표와 중심 간 거리 2.6을 유지. 표적 링 표시 |
| 일제 사격 | 즉시 + 0.18초 여운 | 전 총의 섬광·탄도·반동을 먼저 생성한 뒤 피해 적용. 첫 발에 적이 죽어도 나머지 총의 발사 연출 유지 |
| 시간 복귀 | 0.22초 | 시간을 원래 배율로 부드럽게 복귀한 후 조작 잠금 해제·본체 복구 |

비행 폭은 `flightArcHeight`(기본 4.2), 시간은 `flightSeconds`, 비행 중 회전 수는 `flightRollTurns`(기본 1, 0~2)로 조절한다. 회전은 비행 진행도 80% 지점까지 끝내고 이후 조준 정렬을 유지한다. 모든 총이 플레이어 몸 위치에서 출발하며, 이웃한 총은 위아래 반대편의 큰 곡선을 사용한다. 도중에 대상이 죽어도 마지막으로 기억한 목표 지점까지 이동해 발사한다. 표적 링과 명중 이펙트는 같은 지점에 중복 생성하지 않고, 총구 섬광·발사 탄도·반동은 총마다 별도로 재생한다.

총 수는 `5 + max(0, floor(bulletRate)-1)`이다. 기본 스탯 1이면 5정, 2이면 6정, 3이면 7정이다. 체력 높은 적부터 정렬하고 균등 분배 후 남는 총은 상위 체력 대상에게 우선 배정한다. 추가 탄환이 있으면 대상 수 상한도 총 수만큼 늘어난다.

조작 잠금은 [Player](../Assets/PlayerSystem/Player.cs)의 소유자별 잠금으로 관리한다. 서로 다른 잠금을 임의로 해제하지 않는다. 무기 비활성화·재등록·소유자 사망 등 중단 경로에서도 시간·입력·시각 오브젝트를 정리한다. 시간 복구 때 0에 가까운 배율로 나누는 방식을 제거해 취소 시 배율이 튀는 것을 막았다. `TimeScaler`의 소유자별 배율로 회피의 한시적 감속과 샷건 정지를 독립적으로 합성하고 해제한다. 필살기 중 회피 슬로모션이 만료돼도 이전 감속 배율이 남지 않는다.

## 유탄 발사기

### 일반 공격 장판

장판 안에 있으면 **진입 즉시, 이후 0.5초마다 접촉 피해**를 받고 화상이 갱신된다. 접촉 피해 계수 기본 4%, 화상은 1초마다 8%, 갱신 시 남은 지속시간 2초다. 기본 장판은 반경 2·수명 4초다. `groundDamageCoefficient`, `groundDamageInterval`, `groundBurnSeconds`, `burnCoefficient`에서 조절한다.

대상 중심점 대신 적 콜라이더와 원형 범위의 겹침을 검사한다. 자식 히트박스 여러 개에 닿아도 적별로 한 번만 처리한다. 같은 장판의 화상은 하나를 갱신하고 틱 시계를 초기화하지 않으므로, 계속 서 있어도 실제 화상 피해가 발생한다. 스킬의 3중첩 화상은 별개로 유지한다.

장판에서 벗어나면 접촉 피해는 즉시 멈추며 남은 화상은 최대 2초간 계속된다. 다시 들어오면 접촉 피해 1회를 즉시 적용하고, 밖에 있던 시간만큼의 피해를 몰아 적용하지 않는다. 장판 만료 후에는 남은 화상만 마무리된다.

### 필살기 폭격

참고한 로컬 소스:

- `alveria/Assets/GameFrontEnd/Effects/SkillEffects/Meteor/Meteor.cs`: 0.2초 간격 소형 운석 연속 소환 후 2.5초 시점 대형 운석 소환.
- `MeteorBig.cs`, `MeteorLight.cs`: 대형 운석 감속·시간 정지와 확장 광원을 이용한 마무리.

이 구성을 지원 폭격에 맞게 변형했다. 총 8발·피해 계수·반경·지속 피해 후보는 기존 설정을 유지하고, **7발 소형탄 + 마지막 중앙 대형탄 1발**로 구분한다. 대형탄은 연출만 강조하며 추가 피해 배율은 넣지 않았다.

1. 전체 폭격 구역과 개별 낙하 위치를 링·조준선으로 예고한다. 기본 0.55초.
2. 대각선 위에서 긴 꼬리를 끌며 가속 낙하한다. 기본 0.65초.
3. 마지막 대형탄은 충돌점 위에서 0.4초 체공하며 빛을 키우고, 0.12초 동안 마지막 거리를 급강하한다.
4. 지정 위치에서 섬광·동심 충격파·잔광 파편·잔불을 발생시킨다. 열·전기·물리 지속 피해의 선택 결과에 따라 낙하·예고 색이 달라진다.

`alveria`의 전역 시간을 4096으로 나누는 코드는 가져오지 않았다. 유탄 필살기 동안 플레이어는 계속 조작할 수 있다. 새 [BombardmentSequence](../Assets/PlayerSystem/Weapons/BombardmentSequence.cs)는 무기와 독립적으로 재생되며 폭탄은 지정 위치 도착 시에만 한 번 피해를 준다. 중간의 벽·적 콜라이더에 의해 폭발 지점이 바뀌지 않는다.

시각 에셋은 로컬 `MeteorSmall.prefab`, `MeteorBig.prefab`을 기반으로 만든 `Weapons/Visuals/BombardmentSmallVisual`, `BombardmentHeavyVisual`이다. 원본 레포는 수정하지 않았다. 기존 메테오의 게임플레이 스크립트·물리 컴포넌트를 제거했고, 공통 입자 머티리얼·텍스처는 현 프로젝트의 에셋을 참조한다. 원본에서도 누락된 메쉬 참조 한 종류는 현 프로젝트의 구 모양 메쉬로 교체했다. 잔불은 시각 효과만 추가하며 추가 피해 판정은 기존 지속 피해 한 경로로 처리한다.

## 건/나이프

- 클릭 즉시 발사. 길게 눌러 퍼짐을 줄이는 차지 입력과 테스트용 추가 4발 제거.
- 기본 1발. `floor(bulletRate)`가 2이면 2발처럼 증가한다.
- 전체 퍼짐각 20도 고정. 기존 차지 수식의 시작 최대각 약 39.9도의 절반이다. 단발은 중앙으로, 다중 탄환은 -10~+10도 사이에 균등 배치한다.
- 기존 단발당 기본 피해 계수 50%를 Inspector 필드로 분리했다.
- 표식 대상에게 이동하며 내려찍는 처형은 아트 준비 전까지 보류한다. 해당 동작을 새로 구현하지 않았다.

## 검증 범위

원본 Unity 6000.0.60f1 프로젝트를 업그레이드하지 않고, Unity 6000.3.24f1의 격리 프로젝트에서 런타임 컴파일·원본 프리팹 복사·실제 URP 렌더링으로 확인했다.

- EditMode 규칙·HUD 상태 테스트 29개.
- 플레이 모드 동작 검사 54개: 즉시 입력 잠금, 점진 감속·정지·복귀, 탄환 수 3에서 샷건 7정, 각 총의 목표와 거리 2.6, 실제 피해와 중단 복구·회피 감속 만료와의 겹침, 폭격 예고, 8회 정확한 폭발, 건/나이프 1발→2발·20도 퍼짐, 잠금 소유자별 해제. 추가로 단일 큰 곡선·몸 출발, 첫 발로 대상이 죽는 경우와 비행 도중 대상이 죽는 경우에도 5정 전부의 섬광·탄도가 발생하는지 검사했다. 비행 중 실제 회전과 7정 각각의 도착 시 조준 방향도 검사했다.
- 장판 전용 검사 17개: 콜라이더 경계 접촉·복수 히트박스, 즉시·반복 피해, 화상 갱신·틱 유지, 이탈·재진입·만료·일시 정지, 스킬 화상과의 독립성, 만료된 리스너 정리.
- 실제 캡처: [샷건](Previews/ShotgunUltimate.mp4), [5정 단일 표적 사격](Previews/ShotgunUltimate-AllFive.mp4), [지원 폭격](Previews/BombardmentUltimate.mp4), [HUD 비교](Previews/WeaponHud-catalog.png). 연출 캡처의 대상과 격자 배경은 검사용 장면이며 원본 Play 씬의 전투 녹화는 아니다.

테스트 에디터의 SearchDatabase 시작 인덱싱 예외는 별도로 기록됐으며 무기 런타임 예외는 발생하지 않았다. 원본 전체 Play 씬의 전투·아트 조화와 최종 밸런스 확인은 별도로 필요하다.
